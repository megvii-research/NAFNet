# FDM-Net 工程实现假设

本文件记录论文未唯一定义、但代码必须具体化的选择；它们不是已验证的实验结论。

## 官方主干和插入位置

`basicsr/models/archs/NAFNet_arch.py` 保持原样。新增 `FDMNet` 继承官方 `NAFNet`，在 `middle_blks` 的所有原始块之后按 DFSM → MSMF 顺序追加模块，仍调用官方 forward。编码器、解码器、NAFBlock、跳跃相加、图像残差、零填充与裁剪均复用原实现。本文图中的双向交互尚无计算公式，本实现采用已讨论的瓶颈串联工程方案，不声称实现了未定义的双向更新。

基线直接返回官方 `NAFNet` 类。四组模型共享官方 SIDD-width32 主干设置：width=32、编码块[2,2,4,8]、瓶颈12块、解码块[2,2,2,2]。小样本配置只缩减通道和块数，仍使用完整官方组件。

## DFSM，对应公式（1）—（6）

- 输入输出为同形状浮点 BCHW。CA使用空间GAP、Linear、ReLU、Linear，每张图预测两个阈值，各通道共享。隐藏维度默认max(8,C//4)。
- 有序边界：low=sigmoid(a)，high=low+(1-low)*sigmoid(b)。有限精度下极端饱和可能令边界贴边；代码不承诺任意权重下严格远离边界。
- FFT沿两个空间轴，使用ortho归一化和未中心化频率坐标。径向频率r=sqrt(fx²+fy²)/sqrt(0.5)。
- 可微选择：L=sigmoid((low-r)/temperature)，U=sigmoid((high-r)/temperature)，三个掩膜为L、U-L、1-U，默认temperature=0.05。它们之和为1，但存在软重叠；这不是严格不相交的硬频带。该选择使阈值预测网络可训练。
- 高频幅值除以自身空间均值（下限1e-6）归一化。噪声尺度sigma_n和斜率分别是每通道可学习参数经softplus的结果。式（6）具体化为sigmoid(slope*(normalized magnitude-sigma_n))，输出在0和1之间。
- 实数幅值掩膜保留相位与共轭对称性。低频、中频、抑制后高频相加，再逆FFT恢复空间特征；不拼接、不额外添加输出残差。半精度FFT使用float32计算。

## MSMF，对应公式（7）—（12）

- 从同一个输入构建原尺寸、floor(H/2)×floor(W/2)、floor(H/4)×floor(W/4)三分支，最小维度为1。低分辨率输入采用area下采样，各分支独立3×3卷积，通道数均为C。
- GAP/MLP/Softmax产生每张图三个标量融合权重，沿尺度维归一化。
- 高分辨率细节=第一分支特征减去3×3局部均值。Down_i采用area下采样，G采用1×1卷积+Sigmoid。
- 严格保持公式（9）：Fi_enhanced=Fi+G(Down_i(detail))*Fi，i=2,3；不是直接加细节。门控取Sigmoid时乘法系数为1至2。第一分支增强特征取原值，以补齐公式（10）引用但式（9）未定义的情况。
- A_i使用1×1通道投影和bilinear插值回输入空间尺寸，align_corners=False；按式（10）加权求和，不做通道拼接。
- BSU位于融合之后：1×1 C→1卷积+Sigmoid，单通道空间背景响应广播至所有通道。输出严格为Fcat*(1-Mbg)，没有残差绕过。背景响应升高时正负特征的幅值都不被放大。
- 没有背景标注时，此分支可由重建损失训练，但不能仅凭结构声称它识别了真实背景。

## 验证边界

单元测试和小样本训练只证明功能流程。没有由本工程产生的真实页岩数据集增强成绩，不填入论文中的任何实验数值。CPU验证不能代表GPU/AMP已验证。
