# FDM-Net 训练、验证、推理与评价指南

统一入口为项目根目录 `run.py`；所有命令从仓库根目录运行。模型工程假设见 [implementation_assumptions.md](implementation_assumptions.md)。官方 NAFNet 源码保持不变。

## 安装与小样本流程

使用Python 3.12。先按PyTorch官方安装选择器安装适合CPU或GPU的、相互匹配的PyTorch和TorchVision；本工程CPU验证组合是torch 2.2.2+cpu、torchvision 0.17.2+cpu。然后：

```bash
python -m pip install -r requirements-workflow.txt
python -m scripts.create_smoke_data
python run.py check-data --config configs/smoke.yml
python run.py train --config configs/smoke.yml --variant fdmnet
```

不必执行会重写官方版本文件的 `setup.py develop`，直接从项目根目录运行。生成器写入真实RGB PNG：训练2对、验证1对、测试1对、无参考输入1张。这些是合成流程样本，不是公开数据集或真实页岩实验。指标仅在实际模型运行后产生，生成器不填写任何指标。

生成数据的目录必须不存在。新训练输出目录必须为空；重复运行时指定新目录或使用续训：

```bash
python run.py train --config configs/smoke.yml --variant fdmnet --output experiments/another_smoke
python run.py train --config configs/smoke.yml --variant fdmnet --resume experiments/workflow_smoke/fdmnet/last.pt --epochs 2
python run.py validate --config configs/smoke.yml --checkpoint experiments/workflow_smoke/fdmnet/best.pt --output experiments/val_new
python run.py test --config configs/smoke.yml --checkpoint experiments/workflow_smoke/fdmnet/best.pt --output experiments/test_new
python run.py infer --input datasets/workflow_smoke/unpaired/input --checkpoint experiments/workflow_smoke/fdmnet/best.pt --output experiments/unpaired_new
```

`--epochs`是总目标周期数，必须大于检查点周期；评价输出目录必须不存在，避免混入旧结果。

## 配对数据集和划分

默认目录：

```text
datasets/paired/
  train/input/scene01/a.png
  train/target/scene01/a.png
  val/input/...
  val/target/...
  test/input/...
  test/target/...
```

递归按相对路径和不含扩展名的名称一对一匹配，检查缺失、重名、RGB模式、尺寸、跨组同路径和跨组相同解码像素。只接受8位RGB，不自动缩放参考图，不默默转换灰度或RGBA。训练裁剪、翻转和旋转对输入/参考同步操作；输入小于裁剪尺寸会报错。

支持GoPro等已经解压成RGB配对图像的数据。SIDD MAT/RAW等容器须先按其官方方式导出RGB；本系统不是RAW解码器，不自动下载数据。应保留官方测试集，按场景/序列划分训练和验证。完全相同的像素检查无法发现相邻帧或近重复，需要人工保证场景隔离。

文件名不一致时使用CSV：

```csv
id,input,target
scene01_frame001,train/degraded/frame001_blur.png,train/clear/frame001.png
```

```yaml
data:
  root: ../datasets/paired
  check_content_leakage: true
  splits:
    train: {manifest: train.csv}
    val: {manifest: val.csv}
    test: {manifest: test.csv}
```

配置中的 `data.root` 和 `output` 相对于YAML文件所在目录；split目录、清单以及CSV内的图像路径相对于 `data.root`，支持绝对路径。CLI路径相对于工作目录。内容哈希检查会读取所有图像；关闭 `check_content_leakage` 不会关闭路径隔离检查。

无官方划分的图像池可生成固定种子的清单，不移动原文件：

```bash
python -m scripts.split_pairs --input datasets/pool/input --target datasets/pool/target --output datasets/manifests --ratios 0.8 0.1 0.1 --seed 42
```

再把 `data.root` 指向 `../datasets/manifests`、三组split分别使用train.csv、val.csv、test.csv。样本数必须足够使每组非空。该工具只做图像级随机划分，不自动建立场景级隔离。

## 正式训练及四组消融

`configs/train.yml`提供可编辑工程起点：官方SIDD-width32主干、L1、AdamW、MultiStepLR、梯度裁剪。100周期、学习率和裁剪尺寸并非声称论文已确定或最优的配置。

```bash
python run.py train --config configs/train.yml --variant nafnet
python run.py train --config configs/train.yml --variant nafnet_dfsm
python run.py train --config configs/train.yml --variant nafnet_msmf
python run.py train --config configs/train.yml --variant fdmnet
```

共用同一个配置、随机种子、配对清单、主干和训练超参数；输出分模型保存。只使用train优化、val选最佳PSNR，test不参与每周期模型选择。验证和测试逐张整图运行，支持不同尺寸；训练batch_size>1须提供固定crop_size。

## GPU、检查点和日志

- CPU wheel不具备CUDA能力，GPU机器须安装适合驱动/硬件的PyTorch和TorchVision。`device: auto`自动选择CUDA/CPU，`--device cuda:0`强制指定；无CUDA时明确报错。
- 支持单GPU，不包含分布式训练。`train.amp: true`只在CUDA启用混合精度与梯度缩放。本次CPU测试不代表GPU/AMP已验证。
- 默认正式配置关闭严格确定性；CUDA部分算子在严格确定性下不支持反向时会报错，不删除模块规避。
- PyCharm/Windows初始使用 `num_workers: 0`，再按机器情况增加。
- `run.log`记录逐步损失、梯度范数和逐图指标；`history.csv`记录逐周期损失、学习率与验证均值；`config.json`和`data_manifest.json`记录配置及数据来源/哈希。
- `last.pt`用于续训，`best.pt`用于评价，`epoch_XXXX.pt`按save_every保存。检查点包含模型、优化器、调度器、缩放器、周期、步数和各随机数状态，读取使用weights_only=True。
- 续训按周期边界恢复，不从中断batch恢复；使用同一数据/配置，仅扩展总周期数。数据或关键配置改变会被拒绝。
- 如中断留下尚未完成的val_epoch_XXXX目录，核实后移走该不完整输出，再从最近完整last.pt恢复；不要把旧检查点恢复到已有后续周期结果的目录。
- 接受本流程检查点格式，官方预训练.pth不是完整续训检查点。要迁移官方权重需另行做显式权重转换。

## 无参考真实页岩图像推理

```bash
python run.py infer --input /path/to/shale_rgb --checkpoint experiments/paired_training/fdmnet/best.pt --output experiments/shale_new --device cuda:0
```

支持单张RGB或递归目录，没有参考图参数。只计算NIQE，逐图CSV和汇总中不生成PSNR/SSIM字段。全图推理不自动缩放或分块；显存不足时选择足够显存的设备或CPU，避免改变评价协议。

每次评价保存 `images/`、`per_image.csv`、`per_image.json`、`summary.csv`、`summary.json`、`run.log`。汇总记录有效/不可用数量；CLI评价还记录检查点SHA256。所有分数从实际增强像素计算，没有模拟分数。

## 指标协议

- 对保存的同一组RGB uint8像素评价：输出clip到[0,1]，乘255并四舍五入保存PNG，不另做对齐或增强。
- PSNR：RGB MSE，范围255，单位dB。完全相同为正无穷，CSV为inf，JSON以+inf字符串保存。
- SSIM：scikit-image RGB通道均值、11×11高斯窗、sigma=1.5、总体协方差。不是仓库默认强制CUDA的3D SSIM。
- NIQE：复用仓库BasicSR自然图像统计模型、Y通道、96×96非重叠块，第二尺度使用其OpenCV线性下采样实现；与MATLAB抗混叠实现有差异，比较时统一协议。
- 默认不裁边，`metrics.crop_border`用于训练验证和配对CLI评价，CLI可用 `--crop-border`覆盖；infer默认0。
- SSIM不足11×11、NIQE少于两个96×96块或统计退化时记录为空并说明原因，不缩放以凑分数。按图像取算术均值，只聚合有效项，全部不可用时为空/null。
- NIQE不等价于页岩颗粒结构、分割或粒径统计准确率。没有实际数据集实验就不能声称达到论文数值。

## PyCharm配置

打开项目根目录，选择安装了依赖的Python解释器。Run → Edit Configurations → Python，Script path选根目录 `run.py`，Working directory设为仓库根目录，UTF-8输出。

| 运行项 | Parameters |
|---|---|
| 数据检查 | `check-data --config configs/train.yml` |
| 小样本训练 | `train --config configs/smoke.yml --variant fdmnet --output experiments/pycharm_smoke` |
| 正式训练 | `train --config configs/train.yml --variant fdmnet` |
| 续训 | `train --config configs/train.yml --variant fdmnet --resume experiments/paired_training/fdmnet/last.pt --epochs 120` |
| 配对验证 | `validate --config configs/train.yml --checkpoint experiments/paired_training/fdmnet/best.pt --output experiments/val_new` |
| 配对测试 | `test --config configs/train.yml --checkpoint experiments/paired_training/fdmnet/best.pt --output experiments/test_new` |
| 无参考推理 | `infer --input /path/to/shale_rgb --checkpoint experiments/paired_training/fdmnet/best.pt --output experiments/shale_new` |

复制正式训练运行项，仅修改variant生成四组消融配置。含空格的参数路径加双引号。入口具有Windows多进程需要的main保护；不要直接运行workflow/engine.py。

验证命令：

```bash
python -m unittest discover -s tests -v
python -m scripts.verify_fdmnet
```

测试会实际生成图像、训练四组小模型，并验证续训与连续训练一致性；CUDA测试在无GPU机器上明确跳过。单元测试不是图像增强效果实验。
